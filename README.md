# Phishing Website Detection Using Machine Learning

A CLA-3 machine-learning case study comparing four classifiers on the **UCI Phishing Websites** dataset.

## Project objective

Use website-related features to classify records as phishing or legitimate, then compare model performance using a held-out test set.

## Dataset

- Source: UCI Machine Learning Repository
- Dataset: Phishing Websites (ID 327)
- Records observed in this experiment: 11,055
- Input features: 30
- Target labels in the source dataset: `-1` and `1`

Dataset page: https://archive.ics.uci.edu/dataset/327/phishing+websites

**Important:** This notebook uses the pre-extracted features supplied by the dataset. It does not fetch a live URL, crawl a website, or perform a live security scan.

## Models compared

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Support Vector Machine (SVM)

- Train/test split: 80:20
- Stratification: enabled

## Important evaluation limitation

The initial data inspection found **5,270 duplicate feature rows**. The experiment retained those rows before a random stratified train/test split. Duplicate or identical feature vectors may therefore appear in both sets and could make the reported test performance optimistic.

A stronger follow-up evaluation should inspect duplicates for conflicting labels and use a duplicate-aware split or a carefully deduplicated dataset, followed by cross-validation. Interpret the reported scores with this limitation in mind.
